# Space artwork

This directory contains original project background artwork shared by the
Windows and Godot implementations. Browser-ready derivatives are maintained
alongside the Web asset pipeline.

The runtime uses the sector plates in their original orientation and combines
them with separate scenery layers. The images are designed for repeatable use;
foreground objects remain independent visual or physical elements.

These files are project artwork. This record does not grant rights to third-party
content or certify ownership of assets outside the project. Internal creation
prompts and art-direction notes are not included in the public repository.
